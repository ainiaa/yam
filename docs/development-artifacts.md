# 开发产物归档规则

作者：Jeff.Liu

Git 保留源代码、测试、构建配置、锁文件、运行时校验清单、许可证材料，以及 Markdown 计划和验收摘要。测试实际读取的数据不能作为临时产物删除。

原始测试/构建日志、性能采样、中间评审 JSON、工作区快照及机器执行计划归档到仓库外，不随功能代码提交。新产物应写入 `.artifacts/` 或外部归档目录，不在 `docs/evidence` 继续积累。

2026-10-04 整理时先备份完整 `docs/evidence`、计划及相关 Markdown，再逐文件校验 SHA-256，随后移走 2,884 个尚未跟踪的非 Markdown 证据与机器计划（压缩归档约 10 MB）。历史已跟踪证据保留，本次不改写 Git 历史。

本机归档位于 `~/.local/share/yam/development-archives/` 的日期目录，每份包含 `development-evidence.tar.gz` 和 `manifest.json`。归档不随 Git clone 分发，需要完整证据时单独移交；仓库摘要不保证原始证据可从 Git 取得，也不代表当前提交重新通过原生验收。

恢复时先核对清单与压缩包校验值，将需要的文件提取到独立临时目录；不要直接覆盖当前源文件。已有验收记录中的原始路径和哈希属于历史记录。
