# B01b：已保存项目上移／下移

作者：Jeff.Liu

主窗口侧栏中，已保存且目录身份唯一的项目提供 ↑/↓ 按钮，每次移动一个相邻位置。首项上移、末项下移及单项目两键禁用；派生项目和 secondary 窗口不提供入口。仅交换保存数组的相邻对象，项目目录、显示名、当前项目、折叠状态、会话、布局与进程保持原样。

操作同步读取最新项目集合，先保存再更新当前状态，通过既有偏好发布让第二窗口接收顺序，接收端零回写。连续点击各用最新顺序；目录验证等待期间的 Add project 保留已发生的重排和改名。无效方向、目标删除、字面目录变化、重复标准化目录及边界操作零写。存储或序列化失败保留原顺序并显示错误，用户可再点重试；异步发布失败保留已保存的本地顺序并显示原有跨窗提示。

## 证据与边界

68 项定向、1274 项完整前端测试、build 和 diff 通过，最终四检查 target-final/full-final/build-final/diff-final 前后均精确绑定 184 文件，4 个 owned 路径、零越界漂移。源码摘要：`53fb87247c53bb396d005d5ef96e748594f3a50b702f9e65585e131bd0cd7f20`。独立审核 68 项定向与 3 个实际 callback probe 通过，分组不加总唯一测试数。

测试先行实际 UI 缺移动按钮取得语义 RED；新 helper/handler 缺失属于 scaffold。后补实际 JSX、facade、secondary 和边界回归如实记录为实现后验证。一次夹具复用已改单项目的状态导致 disabled 断言失败，按方向独立夹具后保持原断言通过。root 初次误用保留的失败 target-current 检查映射，已依 sourcefreeze 指定 target-final 修正，原始历史保留。
