# Codex 会话配置继承（Jeff.Liu）

## 已批准的边界

YAM 新建 Codex 网关会话使用原 Codex 配置、MCP、技能、插件和指令的私有快照；仅覆盖模型连接和隔离运行所需的存储位置。不复制 Desktop 登录凭据，不修改原配置、资源或 auth。普通终端和旧会话行为保留。

默认图片行为沿用 Codex；可选「Gateway image API」保留现有成功的 imagegen API 引导，不自动切换路线。两个模式均传递进程环境和私有 CODEX_HOME。配置快照标识随历史保存，恢复使用原快照。模板只保存用户选择，不复用会话标识。

## 顺序与验收

1. 测试先行：配置合并、资源继承、认证隔离、配置错误、路径与私有目录、恢复和子进程。复用已批准的锁定 TOML 依赖；主进程、角色配置和 profile 固定到选定连接。
2. 新建界面、项目默认和模板增加两个图片模式；仅 Codex 网关显示，原生为默认；新建分配独立快照，历史保留标识。
3. 本地假网关验证实际 Codex 的配置、MCP、子进程、认证和图片 API；全量回归、构建、多模型只读复审后更新并重启唯一 YAM。

## 证据边界

不额外调用真实厂商图片接口。现有真实图片证据保留，但不能代替新实现验收。CLI 原生工具的提供方/登录方式限制如实报告，不伪造 Desktop 登录或注入原生图片工具。Converge 旧失败回执保留；侦察输出未通过结构校验，不当成通过证据。
