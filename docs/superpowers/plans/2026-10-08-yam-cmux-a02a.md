More actions → Terminal profiles 或命令面板 Terminal profiles 打开管理窗口，支持保存、更新、复制、删除、设默认和显式启动。管理和选择不执行；配置仅包含名字、Shell/login、启动目录策略（上下文、home、绝对字面目录），不套用旧 Agent 模板。未设默认时普通新建沿 A01b；明确选择优先于默认，Profile 的 Current default Shell 明确沿 legacy。项目行本次目录参数优先；home 由 owner 解析。

独立 `yam.terminalProfiles.v1`，最多32项、名字80 Unicode codepoints、路径4096 UTF-8 bytes、整体524288 UTF-16 codeunits。严格字段和数据描述符，拒绝 getter/序列化钩子/额外字段/稀疏数组；保存先写存储，成功才更新内存，失败保留 draft、集合和默认。坏数据或悬空默认可见且不覆盖；隐式新建零执行，显式 Start without profile 使用普通偏好恢复启动，保留原始损坏数据。首尾空白目录拒绝，内部空格与 Unicode 保留；可跨平台保存，实际使用显式目录及 Shell 时按当前平台校验，失效项报错、不自动换配置。

前端普通启动在 await 前取快照，沿原 admission/容量机制，一次调用及释放；高级 Agent/custom/resume/项目执行/worktree 不读取 Profile。没有新增 wire、Rust 或依赖变更；没有环境引用、Profile 外观或可信项目 Profile，这些继续后续切片。
