# A02c2：保存布局中的终端外观恢复

作者：Jeff.Liu

布局成员标签保存各自最近的字体、字号和 symbolic theme。下次恢复时，在当前 owner/claim 核实后，真正新建的 renderer 使用该外观；已有缓存视图保留实际外观，显式新启动和跨窗移动继续采用各自已有优先级。未注释成员使用全局默认；布局之外重新打开历史不获得通用外观记忆。System 在本窗口解析当前颜色，不保存 OS 颜色值或 Profile 身份。

App 保存 v5：原 v4 树加可选 appearances map，最多 16 个真实成员，三字段沿既有外观校验。旧 v1–v4 和 fallback 返回原形状；无 map 的旧编码调用仍输出 v4。decoder/bootstrap 只读，成功的旧布局 App 恢复仍沿原行为自动保存，现可升级 v5，不能称成功 mount 零写。bootstrap 只传会话 ID；owner 去除成员时同时去除注释。core 最多 4KiB、全 JSON 最多 32KiB UTF-8；最大合法 font/ID 转义实测可往返，不收紧旧字体限制。

现有保存 effect 只收集布局内成员；尚未创建视图的成员保留已验证注释，不被全局值抢先覆盖。global Apply、zoom 和 secondary commit 经现有路径更新外观，单个本地 revision 触发布局保存；OS palette、字体 ready、行高和 cursor 不新增触发。全局写失败不改变视图；布局写失败保留旧 raw 与已应用外观、显示错误，下次显式 Apply/布局操作重试，不伪造回滚或重启。

无效 v5 整体拒绝，沿 A02c2a 既有 gate 保原 raw，不部分恢复，invalid Retry 不可用；显式新建出口、有效 owner 失败 Retry 和 16-view 预算不变。
