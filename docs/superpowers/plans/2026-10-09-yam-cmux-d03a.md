主窗口 More actions → Connect SSH，输入 `alias`、`host` 或 `user@host` 与可选端口，点击 Connect。macOS 使用固定系统 `/usr/bin/ssh`，保留原生 SSH 配置与认证行为；不读取或编辑用户配置/密钥。输入仅支持有限 ASCII 名称，暂不支持 IPv6、URI、远程命令、Mosh 或额外 CLI 参数。

成功会话保留 typed SSH 身份，标题为纯文本 SSH 目标，历史详情可显式 Reconnect。每次点击捕获当前全局保留行数与终端外观；不继承 Profile/Shell/Zsh/env 启动设置，不自动重连，查看/恢复现有会话不重新启动。

启动结果 Unknown 时，当前原生窗口 epoch 暂停新的逻辑启动，提示查看已有会话。既有会话仍可操作，另一窗口保持正常；没有可信自动解除入口，不用时间、目标名称或空列表推定安全重试。保留既有全局16预算与未知占用。
