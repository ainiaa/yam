# YAM 体验优化执行计划（2026-10-24）

按当前 0.1.7 工作区顺序实施；保留既有未提交改动。目标是稳定、简单的原生 CLI 工作台，不新增依赖或 AI 执行框架。

## 顺序和验收

1. **窗口恢复**：检查隐藏、重新显示、正尺寸适配、迟到帧和焦点；恢复不需要切换标签，不重新启动 CLI，不夺取用户新焦点。
2. **启动反馈**：保留单次启动；检查弹窗关闭与首帧的关系，区分 YAM 创建、原生 CLI 加载、原生授权等待。不自动信任钩子，不把授权页称为可输入。
3. **状态一致性**：后台进程状态优先于旧代理事件；已结束、未知集成和等待授权必须如实展示。
4. **快捷操作**：复用已有新建、复制、命名和菜单组件；检查键盘、点击外部关闭与配置继承，不重放提示词或恢复旧会话。
5. **交付核对**：完整前端回归、构建、适用原生回归，核对候选版本和公开更新版本，逐项记录无法验证的内容。

## 实施规则

- 每步先写可执行回归，再修已复现问题；已正常的行为保留。
- 不修改全局 Codex 配置、认证、MCP、skill 或 ChatGPT Desktop。
- 现有 CLI、子代理和子进程语义保持；测试默认不调用真实厂商、不启动其他桌面应用。
- 当前运行会话不停止。需要完整更新重启时，先完成可审阅候选；有运行任务时再取得中断授权。
- 不为消除提示而绕过 Codex 原生权限确认。
- 公开仓库当前发布落后于本地候选，不能把本地安装等同于正式上线。签名公证凭据仍缺失；预览包应明确标识。
