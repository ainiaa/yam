# YAM 体验与交付优化方案

作者：Jeff.Liu。基线：0.1.9 / f8ccdcf。用户已授权先规划再顺序实现。

## 原则

保持原生 CLI、子代理、子进程与全局 Desktop 配置隔离；复用现有终端、通知、Git、文件预览和深色组件。不增加依赖，不重做 AI 执行器。先补正常、边界和异常回归，再实施。当前运行任务不终止；涉及重启时先检查活动任务。

## 顺序

| 阶段 | 结果 | 验收 |
| --- | --- | --- |
| T1 | 可靠恢复窗口与终端视图 | 重开 GUI 不重启任务；恢复原标签、PID、输入与焦点；失败可原位重连 |
| T2 | 完整启动阶段计时与即时反馈 | 单次启动；区分创建、首帧和原生就绪；提供样本统计而不伪造 GUI 耗时 |
| T3 | 多会话状态与标签导航 | 运行、待处理、已结束筛选；进程与代理状态分开；搜索并定位标签 |
| T4 | 通知定位与可诊断提醒 | 原事件定位和已读语义不变；重要事件可见；测试通知入口不绕过系统设置 |
| T5 | 可复用连接选择 | 命名保存连接引用；不保存密钥；原 CLI 配置默认；不修改全局配置 |
| T6 | 设置搜索与一致交互 | 搜索中英文设置项；保留各页未保存确认；统一导航与返回 |
| T7 | 脱敏诊断导出 | 导出版本、状态、启动耗时；不导出环境变量、密钥、对话或完整本机路径 |
| T8 | Git 变更与产物入口 | 复用既有差异和文件预览；显示分支和修改状态；不自动执行 Git 写操作 |
| T9 | 偏好备份与安全导入 | 只导出白名单偏好；不含认证、会话内容和运行布局；导入前验证并可取消 |
| T10 | 当前能力与发布交付核对 | 当前版本能力独立于历史；回归、构建与安装验收；签名公证无凭据明确未覆盖 |

## 产品约定

- 关闭视图、停止进程、继续原生对话、再次运行明确区分。恢复与重连从不创建 CLI。
- 默认新建仍最少操作；连接引用、诊断、备份等放入既有高级入口。
- 系统通知权限／勿扰／共享屏幕规则由系统控制；应用不静默修改。
- 连接和备份只存引用，不导出 API key、认证、对话、运行布局或其他 App 配置。
- 工作目录共用的并行任务可提示冲突风险，不自动分支、worktree、提交或合并。
- 知识库、模型竞技场、插件市场、完整浏览器、云任务不在本轮范围。

## 交付

每项保留源码、测试和实际界面证据，最后执行整体回归、构建、包校验及安装验收。窗口工具失败只标记对应验收缺口，独立事项继续。Apple Developer ID／公证凭据尚无，正式公证不能声称完成。Windows／Intel／Linux 不用 Mac 测试替代。公开发布新版本前提交具体材料请求授权。

## 实施进度（候选 0.1.10）

- T1：通知初次查询、监听注册、二次查询失败及通知清除的恢复分支均已补红绿回归；有效记录独立恢复，迟到失败不覆盖新选择。真实 GUI 热重开另记。
- T2：表单立即关闭、可见工作区提示；明确失败恢复表单、未知结果不自动重试。创建／视图挂载各保留最多 32 个纯数字耗时，P50/P95 明确不代表原生就绪。
- T3/T4：现有筛选与命令面板前置、未读标签、显式测试通知与系统设置说明；通知导航关闭数据页。
- T5/T6：复用模板保存连接引用，参数与提示词不复制；设置中英文搜索保留未保存确认。
- T7：复用现有脱敏报告与原子、不覆盖文件保存；增加有界数字耗时，拒绝未知字段。
- T8：复用差异／工作树与安全路径预览；状态栏前置分支、目录共用提示及文件定位，不执行自动 Git 写操作。
- T9：白名单备份、预览确认、校验后写入、失败回滚；保留旧模板及背景图片，损坏连接存储拒绝覆盖，未知错误不回显路径。
- T10：0.1.10 候选版本及 notices 的第一方版本摘要已更新，第三方依赖逐项未变；发布工具 86 项通过。正式公开版本仍为 0.1.9。
