作者：Jeff.Liu。状态：源码、回归与独立 gpt-6.1-sol spec/quality 通过，原生待验；不是完整 A01/S1 或 cmux 对等。

## 用户路径与边界

Terminal settings 中的 Shell for new terminals 提供 Current default、System default with explicit options 和 Explicit executable。Unix 显式模式首批支持 Bash/Zsh/Fish，以字面 executable 参数加 `-i`，按 Login shell 开关选择是否加 `-l`；Windows 显式模式支持 cmd.exe，以 `/D` 启动，不提供 Unix 登录选项。其他 Shell 可继续 Current default，保留现有策略。

Save shell settings 独立保存，不启动进程，只影响之后一键新建的普通终端。高级 Agent/custom、resume、项目执行配置、worktree attempt 不套用普通偏好；正在运行的会话不变。缺省或 Current default 完全省略新增 wire 字段，新旧客户端兼容；旧 owner 拒绝显式配置时显示有界错误，不自动降级重试、重启 owner 或重跑任务。

独立 `yam.shellLaunch.v1` 严格存储 `{version:1,shell:null|{program,login}}`；缺 key、额外 key、类型、平台登录选项、绝对路径语法与4096 UTF-8 byte路径预算均校验。两个 nullable 字段必须存在，直接 Serde 解析也不能补掉缺字段。损坏值可见且不自动覆盖；保存失败保留原生效偏好和对话框 draft。owner 在 worktree preflight/资源分配前检查组合、实际文件及可执行性，不拼接路径或参数，不改用户 rc。A01a home 规则保持。

生产范围仅 App.tsx、TerminalSettings.tsx、shell-launch.ts、lib.rs、background.rs；旧 CLI/worktree 通过原签名包装入口保持行为。仅新增可选 Shell wire 字段；无新依赖、CLI命令或历史schema扩展、Agent模板或项目配置变化。
