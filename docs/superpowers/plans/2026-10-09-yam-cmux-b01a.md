# B01a：项目直接改名

作者：Jeff.Liu

主窗口侧栏中，手动添加的项目提供 **Rename project…**。对话框显示只读目录，修改显示名后选择 Save project name；名称去除首尾空白，允许 1–200 个 Unicode code point。重复显示名允许存在，目录继续标识项目。

本片仅更改显示名，保留目录、项目顺序、折叠状态、当前项目和运行进程。由会话派生的项目及 secondary 窗口不提供改名入口。取消、过期目标、重复目录身份和存储失败不会提交；保存先写存储，再更新当前状态，已有共享偏好路径发布一次。Add project 在目录异步验证后读取最新项目集合，保留等待期间的改名及其他项目变化；写入失败保持原状态。

## 验证与边界

作者 57 项定向、1263 项完整前端测试、build 和 diff 检查通过，四检查前后映射与最终 184 文件完全一致；5 个 owned 路径，无非 owned 漂移。独立审核 57 项定向及 3 个实际 callback probe 通过，分组不作为新增唯一测试数加总。源码摘要：`5e3a0b8a49be65614806c0e07c15fa8c8029e0b029260bd6082e29ee09187d5f`。

测试先行取得两个真实语义 RED：原侧栏缺少改名入口、原 Add project 在写入失败时仍提交 UI 状态。缺失新函数/validator 属 scaffold；latest-ref fixture 未模拟真实 React 状态、旧共享偏好 effect selector 与 callback 转译 strict directive 返回字符串属于夹具失败，原始日志均保留。修正真实绑定后保留所有原断言；新增 facade 失败回归确认本地已保存状态保留并显示现有跨窗通知错误。

本片未运行 Rust 或 coverage，也未进行 GUI/ReactDOM/原生操作验收。不是完整 B01 或 Suite 完成；自动更新保持暂停。R9 历史测量和构建回执不变，独立性能工具工作不属于本片 finding。
