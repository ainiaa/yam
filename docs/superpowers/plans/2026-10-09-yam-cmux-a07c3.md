# A07c3：跳转到终端上报的提示符位置

作者：Jeff.Liu。日期：2026-10-09。有限源码与独立 spec/quality 审核通过。

普通本地、仍在运行的终端可在 More actions 中选择 **Previous reported prompt** 或 **Next reported prompt**。仅使用解析器收到的提示符标记；没有可用位置时按钮不可用。操作只滚动终端，不发送输入、不执行命令，也不启动或重启会话。上报位置可能与可见提示符不同，不能保证精确 PS1；命令活动和退出码仍是不可信 Shell 输出，不证明进程或 Agent 完成。

每会话保存最多100个公开 marker，按当前有效位置去重并限制到可滚动范围，严格选择前一/后一位置，不循环。清屏、重置、切换备用屏幕与关闭会话清理标记。历史保存剥离导航元数据，旧解析器或缺失/无效可选描述不会让有效画面失败；动作前重新核实当前 parser 实例与描述。当前视图/窗口 epoch、claim generation、attachment、连接与手动滚动意图隔离晚到结果；每视图只有一个在途导航。
