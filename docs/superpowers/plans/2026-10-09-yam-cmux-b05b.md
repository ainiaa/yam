# YAM B05b：同一 GUI 两窗口显式移动终端标签

作者：Jeff.Liu。

main 与 terminal-secondary 的 More actions 提供 **Move tab to other window**。只移动当前可用的活动终端标签：源窗口先暂停该 view 的输入、滚动与 resize，目标窗口创建/显示成功后准备移动；真实 view/listener/DOM 释放完成才提交 token ACK。目标接受同一预算中的新 generation，读取并挂接原 session，ready 后完成。移动不会创建、重启、恢复 Agent 或停止原 session，保持全局 16 个 view/pending/draining 预算。本片仅同一 GUI 两个固定窗口，不含镜像、拖放或完整 WindowManager。

结果未知时保留 pending，使用 **Check / Continue move** 查询权威 receipt；目标可用 **Open moved tab** 显式接入。查询未准备结果后必须先由 native generation fence 才恢复源 view。目标关闭只能以创建 epoch 对应的实际 Destroyed 为依据，CloseRequested/hide 不算证明；未知/仍在途/解析不确定时不释放。旧 generation 的六类调用零 dispatch，旧 ACK 不删除新 cache；completed token 被反向移动替代后返回 Stale。菜单打开引起的焦点变化不取消已捕获源 view，但实际身份/挂接变化仍失效。

点击时捕获字体、字号与 symbolic theme 三字段；System 在目标本地解析，cursor 沿全局默认。两窗口分别写自己的 layout namespace，写失败提示；这不是 durable 跨窗口事务或跨 GUI 恢复保证。
