# A04b2：macOS 选中文件在 Finder 中显示

作者：Jeff.Liu。

在 macOS，选中当前可见终端中的一个精确绝对文件路径，使用 **More actions → Show selected file in Finder…**。预览显示原始选区和核实后的 canonical path，明确这是本机路径；点击 **Show in Finder** 后再次核实并在 Finder 中显示。Cancel 或 Escape 不显示文件。路径不会 trim、解码或扩展，空格、百分号及 `:line` 是文件名本身；不从 cwd 猜路径、不自动识别输出。

仅接受现存普通文件，允许 symlink 指向普通文件，原串和 canonical 各限4096 UTF-8 bytes，拒绝控制符、双向控制、无效Unicode和多行。后台只检查 metadata，不读取内容、不执行文件、不打开默认应用。动作仅 macOS 可用，main/secondary各自可操作；每窗口最多一个真实任务，取消GUI等待不会提前释放仍在执行的阻塞任务。TUI鼠标模式、其他modal和旧选区/view/缓冲区/附着/布局身份被拒绝；自己的预览对话框移走终端DOM输入焦点仍可确认。native epoch在IO前、IO后及显示前复核；不新增依赖、capability或owner wire，不发送PTY输入或写偏好。
