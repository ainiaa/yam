# 隐藏终端视图内存优化计划

作者：Jeff.Liu。

目标：释放已结束会话的闲置隐藏前台视图，减少浏览历史会话后的重复现场成本。运行中会话继续保留快速切换和缩放同步，不停止任务，不减少后台 2000 行历史，不改变冷启动恢复语义。

本次原生实测启动后 WebKit GPU 从 68.1 MiB 回落至 15.2 MiB，WebContent 从 74.0 MiB 回落至 58.5 MiB；后台与内核约 29.3 MiB。短窗口未复现持续增长，不能把此前峰值直接认定为泄漏。

范围：TerminalViews、App 选择协调器、保存现场确认、现有选择回归及隔离原生 WebKit 对照脚本。兼容新增可选内部 persisted 标记；依赖、任务及系统权限不变。

- [x] 先补失败回归：已结束可恢复视图切换后释放；切回完整恢复；运行中、旧日志视图、正在解析及正在更新视图保留；过期选择不能释放当前视图。
- [x] 增加 TerminalViews.retain，并只在成功完成最新选择后清理已结束且不再需要的视图。
- [x] 执行完整前端测试、构建、WebKit 启动 smoke。
- [x] 对固定 16 会话、2000 行输出的隔离原生 WebKit 夹具测量保留/释放两种策略，确认内容等价及实际内存收益。
- [x] 独立审查并记录收益、切换开销和未覆盖项。

结构化计划为同名 JSON，按 Converge 顺序执行。coverage Provider preflight 返回 uncovered：未配置可执行 coverage 命令；此缺口不能作为完成机器回执。项目实际测试和原生对照仍必须运行。

## 测量与范围调整

完整固定夹具的 coalition footprint 曾为保留 16 视图 173.93–174.11 MiB、释放为 156.93–158.39 MiB。但修正 warm 基线（已缓存时不重新解析）后的另一轮为 168.41–169.85 MiB / 158.75–161.68 MiB；缓存返回 4 ms，重建返回 1017 ms。数据受 WebKit 回收与调度影响，不能当作真实用户 App 的百分比收益。

据此保留所有运行中视图，只释放已结束的隐藏完整现场，避免用内存交换活跃会话的切换响应。独立审查发现候选释放 live 会话会破坏隐藏 PTY resize；补红灯确认，最终删除该候选路径及轻量尺寸 Map，恢复原 resize 行为，并新增 live 缓存及尺寸反转回归。

88 项前端测试通过；TypeScript 工具模块覆盖率 lines/functions 100%、branches 98.62%，App.tsx 协调器由真实 AST 执行测试覆盖，不冒称该文件整体覆盖率。Rust 165 项通过、2 项原生 fixture 默认 ignored；自采样 fixture 本次单独通过，Clippy 与打包通过。

上轮 CI 36959610987 的 macOS WebKit gate 失败：footer 已出现，但异步 fixture IPC 尚未完成。先用 2 秒延迟复现，再在原有 15 秒期限内等完整结果，JavaScript 错误仍失败。新增两项原生延迟/异常回归通过并接入 macOS CI。该失败不是实际采样结果不可用，不伪称该次 CI 全通过。

保存确认边界另经失败回归修复：仅从保存文件校验 session/version/终态与记录 offset 后返回 persisted=true，活动现场固定 false，旧后台缺字段也不释放。保存失败时保留唯一前台现场，不降级为不完整日志。独立 spec/quality 复核通过，另独立执行前端 scoped 35 项和 Rust 保存确认 1 项通过；正式 Review v3 runner 未配置，不声称机器回执。

最终已结束夹具的对照为保留 16 个视图 165.50–166.08 MiB、释放后 151.93–153.18 MiB，约减少 13 MiB；返回开销分别约 5 ms / 1003 ms。这是固定 WebKit 机制夹具，不能当作用户当前单会话的降幅。

新版 GUI 构建于 target/memory-fix/debug/bundle/macos/YAM.app。为保护正在运行的 shell，原 owner/parser 不重启。原后台没有 persisted 字段，因此本次运行保守保留视图，完整缓存清理将在后续自然启用新版后台时生效；不为优化强行停止任务。远程 CI 待本次提交运行。
