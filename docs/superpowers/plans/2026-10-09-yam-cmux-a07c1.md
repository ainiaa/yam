# A07c1：Shell 命令状态接收与显示

作者：Jeff.Liu。

2026-10-09，有限源码/测试与独立审核闭环。普通本地终端可显示 Shell-reported phase 与 Last reported exit code：接收OSC133 A/B/C/D标记，保留有界当前状态，不保存命令文本或事件历史。该显示来自不可信Shell stdout，不能代表Agent或进程真实状态。当前尚未自动注入Zsh发射器，提示符跳转也未实现；没有标记时显示Not reported。

真实已安装parser处理碎片BEL/ST与独立session。重复状态幂等，异常标记、RIS、CSI2J/3J、DEC47/1047/1049与alternate报告清除；公开ESC/CSI observers返回false，真实场景与原解析器相同。安全整数序号饱和后不可用，不wrap。原生可选三字段严格验证，缺失last_exit拒绝；无效metadata不损伤scene，live serde保留合法字段，saved decode与final save剥离内外metadata。Agent/custom/SSH/ended/persisted不显示。

实际App异步回调绑定当前view/instance/claim generation/attachment/lifecycle/connection；missing、冲突或lower sequence清显示但保highwater，同序号不能复活旧结果。parser失败清显示，新的合法较高序号可恢复。renderer reset不清同帧authoritative报告。

验证：1152 full前端与coverage99.73/93.65/96.31、build、native receiver2/cwd6、fmt/clippy all-targets -D warnings/diff通过。独立66项前端、2项native receiver及1个外部actual renderFrame synthetic probe通过。旧31 directed是在parser-failure新增回归之前，非最终target binding；最终full/coverage覆盖最终字节。真实Node缺snapshot、native live serde丢字段、App不发布报告、parser failure残留均有semantic RED→GREEN。

夹具scene空串/scrollback默认/旧revision期望，以及首次full1151的30missing-helper失败、affected325的B未注册失败保留，补真实依赖/注册后原断言全部通过。一次宽Rust a07筛选26项含既有私有test-owned Zsh/PTY，属于执行范围偏差，非本片计划验收；无用户owner/GUI/network，原回执保留。后续约束检查为receiver2/cwd6。新模块未存在/错误cwd等scaffold问题不冒semantic RED。
