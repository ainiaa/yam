# YAM A05a3：未来普通终端的保留行数

作者：Jeff.Liu。

Terminal Settings 提供独立的 Terminal retention 表单，可保存 200–2000 的整数行数，默认 2000。保存成功后只影响之后显式新建的普通终端和个人 Profile 终端；已有、恢复、缓存和跨窗口移动的 view 保持完整 frame 记录的容量。保存不改当前 view，不发送 PTY 输入、不 resize/fit/reset，也不重启会话。Agent、Custom、resume、项目配置和 worktree 启动不继承此偏好，非法非默认组合在分配前拒绝。

偏好先成功写入再更新未来启动快照；main 一次发布，secondary 接收不回写。损坏或读取失败保留原始数据、显示固定错误，并使用安全默认 2000。普通点击在任何 await 前捕获值，重试同一启动请求保留原值。GUI wrapper、owner 严格入口和 parser 完整转发；默认 2000 在 App 和 parser create 请求中省略，显式 GUI Some(2000) 仍按可选参数约定转发。旧严格 parser 对非默认新字段明确拒绝，无降级重试；匹配拒绝不把现有 parser 标 failed 或杀掉。

parser 容量在创建时固定，resize 不改变；normal/alternate/final projection 的 retained_lines 由已验证完整 frame 传递。旧 frame 缺字段按 2000，present null 或非法值拒绝；renderer 在 reset/write 前验证完整 frame 并采用记录容量。cells 仍按 2000 保守预留，256 parser 会话、global16 view/pending/draining 和原有 frame/history/log 预算不增加。
