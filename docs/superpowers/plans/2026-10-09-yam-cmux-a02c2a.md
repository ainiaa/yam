# A02c2a：无效保存布局原始数据保留

作者：Jeff.Liu

保存的布局损坏或读取失败时，桌面显示现有恢复警告和空白回退界面，保留原始保存数据，避免自动保存或外观设置 Apply 将其覆盖。损坏布局不提供 Retry saved layout，不尝试解析其中会话 ID；用户可显式新建终端退出这一保留状态。有效布局正常恢复/自动保存、owner 读取失败后的 Retry 及全局 16-view 预算保持原样。

最小业务变更是在既有 warning 分支 finish 前设置现有 restore_blocked。没有新布局版本、Profile/外观持久化、schema 或恢复框架。
