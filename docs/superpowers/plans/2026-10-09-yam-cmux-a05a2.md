# YAM A05a2：固定键盘 viewport 导航

作者：Jeff.Liu。

macOS 使用 Command+PageUp、Command+PageDown、Command+End；其他平台使用 Ctrl+Shift+PageUp、Ctrl+Shift+PageDown、Ctrl+Shift+End。三项为固定逻辑键路由，八项可编辑应用快捷键及存储保持不变。现有终端帮助 tooltip 提供提示，不增加设置框架。

只有实际输入聚焦、可见且 connected/non-inert 的当前 ready normal-buffer view，鼠标跟踪为 none、native claim generation 一致时执行。复用 owner/attachment/B05b suspension 守卫；Find visible/busy、选择或指针拖动、所有现有 modal、编辑/data-shortcuts、IME/229/repeat/AltGraph 与忙于解析/投影/resize/return 的 view 均排除。只读浏览不要求 writable。正常缓冲且无鼠标模式的 TUI 不能普遍检测，不承诺完整 TUI 覆盖。

接受时先 preventDefault/stopPropagation，再调用 public scrollPages 一次；既有 onScroll 只发一次 viewport RPC，无并行额外请求。边缘 page 接受但不变化时零 RPC。live bottom 沿既有 bottom:true 权威路径等待确认，不本地假清 unread；retained bottom 沿既有本地分支。public API throw 为当前 view 固定错误，无 PTY/fallback/retry，晚 focus/connection/attachment/generation 回调不影响新 pane。排除时 App 保持传播原样；底库既有 Shift+Page 行为仍可能滚动，不能声称排除键零滚动或必然变 PTY bytes。
