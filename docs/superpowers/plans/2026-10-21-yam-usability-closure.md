# YAM 日常使用闭环实施计划

作者：Jeff.Liu。用户已批准 2026-10-21 产品／架构审查建议，按同一会话顺序实施。

## 目标与边界

统一设置导航和保存，减少会话菜单歧义，收敛新建与模型输入，补齐本机字体发现和回归。保留原生 CLI、后台 owner/PTY、普通终端启动配置、会话私有 Codex 配置与两种图片模式。不新增依赖、不改全局 Codex 配置、不发布 Releases。只安装到既有 YAM.app；有活动任务时保留 owner，完整重启前检查空闲。

## 顺序与验收

1. 设置导航与保存：辅助窗口携带明确目标；未知目标拒绝；主窗口已有模态时不叠开。全部设置先校验，只有一个 Save；失败保留草稿并说明可能的部分保存，取消不写入。
   - 先运行新增的实际组件／跨窗口路由红灯；实现后跑 `node --test tests/terminal-settings-ui.test.mjs tests/settings-navigation.test.mjs tests/native-menu.test.mjs`（apps/desktop）。
2. 会话交互：全局偏好进入应用设置导航；更多菜单保留会话操作，诊断折叠；结束状态直接提供可用恢复操作；历史事件标明上次；不兼容启动程序显示原因及原配置切换操作。
   - 先更新实际组件与菜单契约测试，再实现；回归包括模态阻断、危险操作确认及启动不重复。
3. 输入控件：模型列表搜索与手填使用一个输入；保留当前模型与错误／取消行为。macOS 原生枚举已安装等宽字体，字体与 profile 共用结果；发现失败保留预设与手填并显示原因。
   - 先写模型组件、字体目录正常／边界／失败测试，再实现；不增加外部服务或依赖。
4. 集成：全前端 coverage、native coverage、构建；复核私有配置与子进程继承契约；本地假服务验证；真实厂商和线上更新包未经本轮授权不调用／发布。明确普通 Shell 不自动注入 Agent 网关配置。
5. 安装与界面：主／辅助／最小窗口，设置目标／保存／取消，模型搜索与自定义，字体搜索，结束会话操作、菜单关闭、普通终端输入／删除／查找；空闲预约后安装并重启，核对构建文件、签名和单实例。

## 代码范围

- `apps/desktop/src/` 的设置导航、终端设置、会话界面、新建与模型／字体控件，相关纯函数和样式。
- `apps/desktop/src-tauri/src/desktop_windows.rs` 的设置目标协议、原生字体发现、命令注册和菜单。
- `apps/desktop/tests/` 与对应 Rust 单测；不修改任务执行／停止和网关传输协议。

## 风险与验证原则

设置可能跨多个存储键，验证在任何写入前完成；持久化失败不伪称事务成功。跨窗口命令仍验证身份与 epoch；设置目标只接受有限白名单。字体发现只返回字体名称，不读取用户文档。保留既有脏文件，不提交混合改动。

Converge 路由为 planned/high，native 预检 ready；Node mutation 尚无适配，正式 Trace 仍可能 uncovered，不能以单测通过替代该证据。按项目现有测试门槛执行，不降低门槛。
