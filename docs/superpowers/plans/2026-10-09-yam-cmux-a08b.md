# A08b：终端 System 配色

作者：Jeff.Liu。

全局 Terminal settings 与 Profile 初始外观的 Theme 选择器新增 **System**。它使用当前窗口系统的深浅色偏好，复用现有 dark/light 终端调色板。默认仍是 dark，原有 dark/light/solarized 保持；设置仍为 fontFamily/fontSize/theme 三字段，Profile v3 不变。存储与跨窗口提交保留 symbolic `system`，不保存解析后的颜色。

每窗口独立初始化与订阅媒体状态。缺失、throwing matches 或 listener 安装失败回退 dark；部分安装清理，卸载后的晚回调失效。安装后读取最新状态，不让旧的安装前快照覆盖它。系统变化只重设当前非disposed且自身 appearance.theme 为 system 的 view palette，保留字号和字体，显式主题不跟随；不增加 appearanceRevision、不fit/resize、不开终端、不写存储/广播、不移焦点，不改打开的draft。字体ready已有fit仍完成且不会恢复旧palette。全局Save仍先写成功再更新当时views，Profile仍取新终端初始外观；secondary收到symbolic提交后用自己的本地深浅色。
