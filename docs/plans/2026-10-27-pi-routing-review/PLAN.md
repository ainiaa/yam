# Pi 路由复核与 lint 修复计划

作者：Jeff.Liu

本轮保留已有未提交变更，复核 Pi 路由的配置、能力声明、任务连续性、手动锁定、压缩和重启恢复；修复五处 Clippy 报错，保持官方 CLI、Git 查询和 Node 解析器行为。

1. 先复现严格 Clippy，冻结受影响代码基线；读取调用链并补回归测试。
2. 修复可复现的路由遗漏；lint 仅作等价简化，不关闭 lint 或删校验。Git 的查询/快照/差异/清单仍走同一根实现。
3. 运行路由测试、相关 Rust 测试及完整前后端回归、严格 Clippy，独立只读复核。
4. 重新构建固定单实例 YAM.app、安装并重启；真实验收模型/档位、上下文、历史恢复、普通终端及受影响能力。清理自有测试记录，保留用户任务。

验收：显式模型/推理选择不被静默修改；上下文和恢复仍使用原生会话；故障拒绝隐藏回退；五处 lint 清零；现有检查不退步。测试使用本机已有 CLI/依赖，不修改全局配置。
