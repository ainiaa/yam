# Pi 路由体验优化计划

作者：Jeff.Liu

1. 配置表单：复用现有选择控件，提供 Pi 配置/本机网关、轻量/强模型与高级分类模型；原生目录只读预检，保留高级参数。
2. 扩展状态与控制：Pi 原生会话继续执行；通过仅监听 loopback、独立随机凭据的有界控制接口调用原生 API。YAM 私有目录保存连接描述及公开状态，前端不接收凭据。
3. 紧凑状态栏：显示实际模型、推理、任务判断进度、故障和可用控制；目标与实际执行分开，恢复时从原生消息读取上次实际数据。
4. 独立控制：固定模型仍可自动推理；自动模型仍可锁定档位；一键全部自动。原生分支保存选择；忙碌/陈旧请求拒绝。
5. 故障刷新：同一进程重读目录，检查配置后解锁；不自动重发任务；保留未执行输入。
6. 回归、只读审查、构建、安装单实例 YAM 并实测；记录未覆盖项。

界面采用现有主题、控件和间距，信息渐进展开，不增加常驻大面板、字体或依赖。原有官方 CLI 启动与参数路径保持独立。


验收状态：六步已完成。冻结的 plan.json 保持初始状态；最终结果与限制见 REPORT.md。
