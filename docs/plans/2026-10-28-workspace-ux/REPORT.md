# 侧面工作区、路由摘要与焦点闭环交付

作者：Jeff.Liu

## 结果

- 项目工具从模态弹窗改为常驻侧面工作区，继续使用原有文件编辑、Git、本轮变更、worktree 和反馈组件。宽窗口可用鼠标或键盘调宽并记住宽度；窄窗口使用完整工具区，通过“返回终端”退出。统一保留 22px／窄屏 16px 内容留白。
- 关闭工具区保留文件草稿、差异选择和反馈；隐藏时暂停相关读取。切换项目时同步 Git 作用域，避免文件与 Git 面板指向不同项目。
- Pi 默认展示自动／固定策略、本轮选择和上次实际执行信息；点“调整路由”展开已有控制。折叠和展开不提交模型参数；模型和推理仍独立选择、一起应用，错误在折叠时仍可见。
- 文件打开和差异定位的异步完成遵守原始焦点意图；用户已经切换到终端或其他工作区控件时，不抢焦点。关闭工作区恢复原终端，重开工作区或切换会话后，旧关闭回调失效。
- 文件局部 Cmd/Ctrl+W 复用已有安全关闭／草稿恢复。原生“关闭标签”只操作当前可见文件页中的文件，否则返回终端，避免误关终端或关闭隐藏页文件。
- 桌面实测发现并修复既有 Tauri 传参缺口：路由读取／控制的前端参数改为 `sessionId`，与当前原生命令的默认 camelCase 契约一致；后台协议仍为原有 snake_case。补充了失败与成功测试，并在真实 GUI 中读取状态、组合选择 Sol/max、应用后核对原生 Pi 状态。
- 窄屏额外覆盖原生终端显式 `visibility:visible` 的情况，工具区展开时终端不能越过父级隐藏状态显示或获得焦点。

## 验证与证据边界

1. 先补失败测试，再修复；原始红灯包括工作区结构／宽度、局部关闭、延迟聚焦、关闭重开、原生菜单作用域、差异保留、Tauri 参数及窄屏隐藏。具体日志在 evidence/。
2. 最终前端全量含覆盖率：2003 通过、3 项原有 opt-in 跳过、0 失败。行覆盖率 99.72%、分支 94.27%、函数 96.24%，达到现有门槛。
3. Rust 回归：1056 通过、25 项原有检查忽略，0 失败。Clippy all-targets、-D warnings 通过。
4. TypeScript、Vite、Tauri debug bundle 构建通过；应用签名和主程序／后台 helper 一致性校验通过。
5. 无界面浏览器运行真实 React、CodeMirror 和差异组件：模型摘要折叠不写参数、编辑保存、差异到文件保留草稿、延迟加载不抢终端或控件焦点、文件局部关闭、鼠标／键盘调宽、关闭后返回终端、窄窗口留白与隐藏均通过，页面错误为 0。文件和路由接口在此层使用测试数据，不把它当真实 Tauri IPC 验证。
6. 安装后的原生桌面验收：用现有 macOS 辅助功能权限操作 YAM，打开临时项目文件，编辑并保存，独立读取磁盘确认内容；关闭工具区后辅助功能焦点为 Terminal input。本轮基线捕获、修改后的真实差异内容通过，真实 Git 文件列表和后台 patch 校验通过。Pi 界面读取状态、展开并一次应用 Sol/max，经后台原生状态确认。
7. 原生 Pi／PTY 验收：high→max、固定 Sol/max、同一原生会话身份恢复、删除文件后从上下文回忆、关闭 GUI 后后台任务继续运行均通过；Codex、Claude、Pi 和 Git 的既有全局配置摘要检查通过。没有修改原生执行器、参数解析、认证、上下文或恢复代码，源码基线比较见 native-source-unchanged.json。
8. 第一轮只读复核提出 3 个焦点／原生关闭问题，均先复现再修复；第二轮复核无剩余 finding。之后的 Tauri 传参问题和窄屏显式可见性问题分别通过真实桌面及确定性浏览器用例复现，并完成红绿闭环。

一次桌面测试尝试通过后台脚本向 GUI 持有输入权的终端写入，被原有所有权保护拒绝；后续合成键盘方式没有确认进入 PTY，未计为通过。没有放松终端输入保护。模型与恢复验证使用独立原生 PTY 输入路径；桌面路由应用则单独通过真实控件和原生状态确认。此结果不代表所有 CLI／提供商组合均经过逐项人工操作。

## 安装与清理

安装路径 `/Applications/YAM.app`，版本 `0.1.10`，标识 `com.yam.desktop`。只维护约定的 `apps/desktop/src-tauri/target/debug/bundle/macos/YAM.app`，未创建平行验收应用或新增依赖。

最终包重新安装重启，旧包备份 `/tmp/yam-before-workspace-ux-release-install.zip`。本轮 7 个自建验收会话已标记已读并归档；正常历史恢复为 156 条，活动会话 0，通知暂停恢复为 false。未操作其他会话的已读状态。最终程序／资产、单实例和通知状态校验见 evidence/installed-final.json。
