# 侧面工作区、路由摘要与焦点闭环

1. 工作区非模态可收起和调宽；文件、差异、反馈状态保留，窄窗口无溢出且有留白
2. Pi 默认展示策略与本轮/上轮实际摘要；展开后原有控制、故障重试和错误仍可见，折叠不提交参数
3. 关闭工作区返回原终端焦点；文件定位与关闭遵循焦点，异步操作不抢走其他输入
4. 官方 CLI/Pi 的上下文、参数、恢复及 YAM 既有功能回归通过；安装重启和真实会话实测通过

先失败测试，再逐项实现。仅复用现有组件和浏览器原生能力，不新增依赖、不改 CLI/Pi 执行器。每次改动核对受影响调用及既有草稿/反馈保护；验收只创建临时项目和自建会话。
