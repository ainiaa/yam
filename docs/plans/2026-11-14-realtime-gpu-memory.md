## 执行顺序

1. **归因与基线**：沿实时输出、投影解析、DOM渲染、隐藏视图和系统合成路径定位分配；用只读进程footprint及可取得的VM区域、当前依赖源代码区分JS/DOM、渲染表面和缓存高水位。记录工具权限限制；每个优化必须有可复现证据。
2. **最小修复**：对已证实的问题先写失败测试，再修改共享入口；保持输入、Unicode、VT、选择、滚动、窗口/标签切换、所有者和取消语义，逐项定向复验。不以降画质、丢历史、重启或强制GC冒充收益。
3. **短时配对**：源码固定，完成同窗口大小、同DPR、同输出、同2000保留行、同生命周期的实时/搜索关闭恢复对照；先记录基线并冻结数值门槛，再运行候选。保留所有逐PID内存、CPU、峰值、采样尝试及无效轮次，验证页面和GPU各自是否下降，不能只报告总量。
4. **回归和独立复核**：运行受影响定向用例、前端覆盖率、类型检查、规范debug打包；Rust若未改则验证字节连续性并复用同版本证据，若改则用原生覆盖率执行一次全量，保留Clippy/doctest。按冻结风险做独立只读需求/质量审查，有同范围问题先集中修复和复验。
5. **完整8小时长测**：前述验证通过后固定最终源码、包和核心进程身份，使用本地合成输出，前4小时8任务、后4小时16任务。真实桌面验证当前活动视图，并按阶段覆盖可见/隐藏缓存及搜索关闭恢复；长测期间不构建、不改源码、不重启，不并行跑测试。沿用每分钟最多2秒稳定窗口、最多3次尝试，保留全部原始尝试；核心身份变化、最终不完整、任务异常或睡眠造成采样间断均失败。记录每阶段稳定后的页面、GPU、Node和总量趋势，阶段扩容不与泄漏混为一谈。
6. **闭环**：核对满28800秒的完整样本、趋势门槛、真实GUI交互、全部owned任务确已停止及通知策略恢复；审计最终代码/包/测试/复核/长测的源码绑定和范围。任何长测失败先保留证据、定位并修复，再对最终候选重新跑完整8小时，不把部分时长拼接成通过。

## 验收冻结原则

- 修改前后均保留原有终端行为、2000行与原权限边界，不引入依赖或架构更换。
- 数值门槛在本轮基线结束、候选测量前写入独立measurement contract，之后不下调；若特定优化无可测收益则不把它计作收益。
- 必须分别报告实时WebContent、GPU、进程组的中位数/峰值及CPU；系统分配高水位与真正活对象泄漏需靠证据区分，不用推测代替归因。
- 长测趋势在最终候选启动前冻结；完整时长、原始采样、身份/包/源码稳定性、无隐性漏采、清场都是完成的必要条件。
- 5项既有前端跳过、30项原生忽略按原约定如实保留；未覆盖的系统内部边界明确说明，不冒充零泄漏认证。

## 本轮过程证据

独立计数门控基线`rt-baseline`已完成：2200种子和30条ready后暂停输出，CUA确认30匹配、关闭搜索并返回实时后才释放负载，避免人工操作时差污染输出量。普通文本/SGR各先热身45秒再采25个5秒间隔样本，单窗口120秒，全部原始尝试保留。100×24所有者终端，2000保留行，规范窗口1180×760、DPR2。普通阶段总量中位数364.26MiB、页面174.02MiB、GPU65.30MiB；SGR阶段总量409.85MiB、页面149.53MiB、GPU65.49MiB、Node97.24MiB。页面并未随着SGR总量同时增大，不能仅凭热点推断所有进程都获益。

候选前冻结`measurement-contract.json`：SGR总量中位数≤368.86948MiB（至少降低10%），普通总量峰值≤383.29315MiB、页面峰值≤188.64200MiB，SGR页面峰值≤163.61077MiB、GPU中位数≤65.48527MiB；相同场景/窗口/DPR/保留行/生命周期，不强制GC，不在性能窗口改源码或跑测试。失败保留，不放宽阈值。

只读VM归因：原实例GPU空闲后18.3MiB、历史峰值75.2MiB；基线活动GPU65.5MiB，`owned unmapped (graphics)`约42MiB，另有系统/图形资源和Malloc。页面基线VM记录约146.3MiB，包含JIT、VM及WebKit Malloc和图形分配，不能把虚拟保留地址空间或Malloc allocated直接等同活JS对象。诊断器只读DOM查询确认一个可见终端、隐藏cache视图为0、DOM节点1479，未证实隐藏终端堆积；没有据此做缓存淘汰或画质修改。

Web Inspector内存面板的AX/截图读取连续超时，保留为诊断未覆盖，未取得可靠堆分类；诊断在基线采样和清场结束后执行，未纳入性能比较。确认active_sessions=0及精确规范GUI进程后用SIGTERM关闭本轮诊断实例；随后后台也已退出，空闲退出helper读到旧descriptor连接拒绝，未伪称执行了prepare_update。CUA runtime已重置，后续桌面验收仍须实际恢复并完成。调试快捷键触发的权限错误仅记录，没有放宽任何权限。

根因回归：SGR被普通文本白名单排除，导致同一已同步正常终端重复RIS/全缓冲解析。新增测试先得到28过/3断言失败，再仅扩展白名单接纳完整、无私有前缀的SGR；正常/Unicode/宽字/样式/待换行、持有视口、活动搜索、FIFO及未知控制回退的248项定向测试通过。未增加后端协议、依赖或产品强制GC。

八小时增长口径在运行前冻结：每个4小时任务阶段单独比较第2小时与第4小时的中位数，每窗口至少50个完整观测；页面、GPU、Node和总量各自增长≤max(16MiB,该阶段前窗口中位数15%)。第一小时缓冲填充、4小时任务翻倍及全部峰值仍另行报告，不计作同阶段稳定性泄漏。增长检查是有界验收，不宣称零泄漏。新增判定器/彩色负载测试先5项断言红，再27项全绿；原默认纯文本负载不变，长测显式用`--ansi`及`--check-growth`。一处测试插入位置在修改业务代码前校正，原始和校正后红灯均保留。
