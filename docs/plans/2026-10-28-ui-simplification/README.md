## 原生打包与闭环复验

仍只维护 `apps/desktop/src-tauri/target/debug/bundle/macos/YAM.app`，使用 `pnpm --dir apps/desktop tauri build --debug --bundles app` 构建。现有 `/Applications/YAM.app` 已更新，版本仍为 0.1.10，identifier 仍为 `com.yam.desktop`。主程序与后台 helper 代码、解析器、版本及本机临时签名校验通过；安装包和构建包主程序 SHA-256 一致。旧安装备份保存在 `.artifacts/ui-native-acceptance-20261028/YAM-before-install.zip`。

真实桌面操作发现并修复了 3 个问题，均先补失败测试再修复：

1. 设置关闭时焦点落到页面根部：在子设置窗口接管焦点前记录入口，关闭后恢复；切换设置页保留同一入口，已有新焦点或新弹窗时不抢焦点。
2. macOS Cmd+W 被系统“关闭窗口”先接走：改由应用原生菜单分派，文件区先关闭当前文件，再返回终端；工作区外仍关闭当前窗口。新增关闭命令只允许 `main` 或 `terminal-secondary` 的同名 webview/window，保留原有后台任务生命周期。
3. WebKit 设置搜索框吞掉空查询的 Escape：有查询时先清空，空查询时发送可取消的 dialog cancel 事件，复用各设置页的取消处理；输入法组合输入期间不触发关闭。
