# M4 CLI 适配器首个切片

YAM 内置三个适配器：系统 shell、OpenAI Codex 和 Claude Code。Rust 启动时只负责探测命令是否存在于当前进程的 `PATH`，前端显示可用性；真正启动仍通过现有 PTY 和 shell 命令路径，因此输入输出、停止、日志和状态规则保持一致。

用户可以选择可用适配器直接启动，也可以在命令字段中提供自定义命令覆盖适配器默认值。命令不存在时不会阻塞界面，启动错误会沿用会话失败状态和错误信息。

Codex 和 Claude 适配器支持可选 CLI 参数和启动提示词，YAM 会对提示词做 shell 安全引用后追加到适配器命令。终端输出会保留最近 4096 个清理后的字符，跨输出块识别 `Working`、`Ask ...` 和帮助提示并显示 `Agent working` / `Waiting for input` 阶段；这不会替代进程退出状态。
