# YAM 0.1.12 — 订阅选路、原生协作与恢复改进

作者：Jeff.Liu

本版面向 macOS Apple Silicon，沿用未公证的预览分发方式。

- Pi 自动选路联合检查模型能力、推理档位、上下文余量与计费授权，支持 Luna／Sol／Astra 分档；保留固定选择和已有业务会话。
- 工具任务使用原生会话执行并按需委派同订阅模型；只读问答转入工具执行时创建独立阶段，避免误续接其他任务。
- 补齐故障分类、有效会话标识检查、取消清理与人工恢复指引。结果未知时只读刷新，不自动重发任务或转付费 API。
- 展示实际响应模型、推理档位、失败阶段、选路拒绝原因与本地上下文估算。
- 改进交互式 Shell、导航、工作树启动和分支比较，补充原生协作校准与回归检查。

## 安装与限制

macOS 应用使用 ad-hoc 签名，未经过 Apple Developer ID 签名和公证；更新包使用既有 YAM 更新密钥签名并绑定版本。首次安装如被系统拦截，可在“系统设置 → 隐私与安全性”中允许打开。

本版仅提供 Apple Silicon 安装包。上下文数字为本地估算，模型可用性与额度取决于现有订阅。真实协作四臂均已结束并确认清场，原始评分为 2 通过、2 失败；两份失败产物经事后修复通过独立验证，原评分保持不变。该小样本不足以证明协作一定更快或更省，因此未据此更改协作默认策略。
