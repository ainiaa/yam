# YAM 0.1.3

- 修复干净 CI 环境在前端测试前缺少 Tauri 权限 schema 的构建顺序。
- 固定 Rust 和校验绑定锁文件的检出换行符，保持 Windows 检查一致；许可证原始字节不做换行转换。
- CI 固定 Python 3.12 与已验证的 Rust 1.98.1；平台专属代码按目标编译，WebKit 首次编译和浏览器运行分别计时。
- 清理原生格式差异，修复 Clippy 警告；保留权限、通知和菜单的原有断言。
- Codex API 失败回执改为按事件结构与会话身份判断兼容性，移除精确版本白名单；覆盖已实测 0.162.1／0.163.0，以及未来版本相同结构、取消、成功和未知结构。
- 补配置继承、原生 MCP、子代理、图片 SDK、外部终端协议和通知回归；并发测试使用进程隔离目录。

## macOS 分发状态

本版为 macOS Apple Silicon 未公证预览构建，没有 Apple Developer ID Application 签名或 Apple 公证。YAM 的独立更新签名不等于 Apple 公证。其他平台的安装包和实机验收不由本机构建代替。
