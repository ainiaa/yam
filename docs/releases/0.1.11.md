# YAM 0.1.11 — Pi 路由与会话体验改进

作者：Jeff.Liu

本版面向 macOS Apple Silicon，继续使用未公证的预览分发方式。

- Pi 自动路由增加模型发现、试调用和本机快速配置，默认自动推理最高使用 high；订阅与网关连接保持明确区分，支持按需调整分类和执行模型。
- 会话收件箱集中显示需要关注的事件，并支持定位对应会话；侧栏统一切换会话，简化终端和分屏操作。
- 改进交互式 Shell 中的 Agent 启动、退出与恢复，并完善本机 CLI 发现、事件处理和会话状态。
- 增加 Pi 插件管理入口，以及相关路由、Shell、会话和界面的回归检查。

## 安装与限制

macOS 应用使用 ad-hoc 签名，未经过 Apple Developer ID 签名和公证。更新包使用独立的 YAM 更新密钥签名，两者不是同一回事。首次安装如被系统拦截，可在“系统设置 → 隐私与安全性”中允许打开。

本次未提供 Windows、Linux 或 Intel Mac 安装包。模型可用性、计费和响应质量取决于用户选择的供应商与本机配置；真实第三方账号的所有故障场景以及其他机器的安装组合未穷尽验证。
