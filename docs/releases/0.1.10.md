# YAM 0.1.10 — 日常使用体验优化（macOS 未公证版）

作者：Jeff.Liu

本版整理了 0.1.9 之后已经完成验收的终端、工作区和界面改进，作为个人日常使用的稳定基线。

- 终端进程结束后可直接输入或点击“打开新终端”，在原目录继续操作；继续原 Agent 对话与重新运行新任务分别说明，避免误重放任务。
- 项目、工作区菜单以及设置表单统一主题、尺寸、间距和焦点效果；方向键、Home/End 和 Esc 操作保持一致，保护输入法组合输入。
- 已结束且已读的普通会话默认折叠；当前、固定、运行中、未读和失败会话保留可见，搜索和筛选显示完整匹配结果。新终端使用可区分的默认名称，已有名称保持原样。
- 通知按项目聚合，主动停止保持静默；精简重复恢复提示，并保留底部状态栏、内存与连接状态。
- 补齐文件编辑、草稿恢复、Git 差异与原生会话反馈；设置增加搜索、偏好备份和连接复用；完善 Pi 路由及原生 CLI 配置继承。
- 修正 macOS 后台通知助手的打包与身份校验，发布前验证主程序、助手、版本及完整更新归档。

## 验证

- 前端回归 2052 项通过、3 项外部浏览器检查未开启；行覆盖率 99.72%。
- Rust 回归 1060 项通过、25 项 opt-in 用例默认忽略；发布与构建工具回归 335 项通过。
- 真实 YAM.app 已验收 1180×760 和 640×440 窗口、深浅主题、两个菜单、键盘焦点、常驻状态栏、终端恢复及实际粘贴执行。后台已有任务未中断。

## 安装与边界

提供 macOS Apple Silicon 安装包。应用使用 ad-hoc 签名，更新归档另外使用 YAM 更新密钥签名；该签名不等于 Apple 公证。首次安装如被系统拦截，请在“系统设置 → 隐私与安全性”中允许打开。

本版不提供 Windows、Linux 或 Intel Mac 安装包及实机验收结论。真实 SSH、各 Agent 的所有配置组合和未知故障未被穷尽测试；“稳定基线”不代表无缺陷。已有会话历史与项目文件保留。
