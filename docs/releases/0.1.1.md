# YAM 0.1.1

- Use one dark, keyboard-accessible dropdown throughout YAM. The model picker keeps keyword filtering.
- Organize native menus into File, Edit, View, Session and Window. Reuse existing session, pane, search and settings actions; preserve custom shortcuts and task-safe quit behavior.
- Check for updates at startup and every six hours. Download and verify signed packages automatically when automatic updates are enabled.
- Install only after an explicit Install and restart action and atomic admission by an idle task owner. Preserve running tasks and prevent new starts while replacing the application.
- Keep a macOS backup until signature, application identity and target version checks pass; restore it on failure.
- Keep pending update checks and automatic downloads running when the Updates panel closes; route Add project and Connect SSH from secondary windows to the main window.
- Verify artifact bytes, the configured public key and the authenticated version before preparing release metadata. Reject colliding artifact names.
- Exit the idle background service after preparation, including when the reply is lost. Require the matching background capability before installation.

No global Codex, MCP, skill, plugin or ChatGPT Desktop configuration changes.
