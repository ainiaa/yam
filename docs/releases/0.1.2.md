# YAM 0.1.2

- 统一设置导航：外观、终端、快捷键、更新；个人配置、粘贴、系统入口及实验选项放在高级设置。
- 固定设置标题和底部操作，正文独立滚动并保持自然内容高度；小窗口使用紧凑导航和双列主题预览。
- 页面切换前提示未保存的更改；保留原有取消、保存和校验行为。
- 修复 macOS 快速退出时未读终端尾输出可能丢失的问题，输出完成后再回收进程。
- 保留原生 CLI、Magpie 会话连接、子进程配置继承和后台任务行为。
- 发布前核对源码、Cargo lock、App 版本、架构、完整归档内容、第三方声明和版本绑定的更新签名。
- 自动检查及下载继续保留；安装必须由用户点击，并在所有任务停止后进行，失败时恢复安装备份。

## macOS 分发状态

本轮构建为未公证预览包，未使用 Apple Developer ID Application 证书，也未经过 Apple 公证。首次安装可能需要在系统设置的“隐私与安全性”中手动允许打开。更新包使用 YAM 独立签名进行来源和内容校验；此签名不等于 Apple 公证。

本轮只准备和验收本机 macOS Apple 芯片产物；Windows、Intel Mac、Linux 不附带未验证安装包。
