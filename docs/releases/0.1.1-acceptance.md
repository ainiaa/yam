## Limits and manual follow-up

- GitHub upgrade is not accepted end-to-end: no public newer release has been published. With an authorized newer release, start an owned `sleep 20` task, verify download is allowed but Install is disabled, wait for exit, explicitly Install and restart, then check version/history/single GUI/new owner.
- Windows native release execution and Linux installation are not run in this macOS environment. The temporary-file sharing fix has a real child-process reading test and explicit closed-file boundary assertion; that is not Windows OS acceptance.
- Apple Developer ID/notarization credentials are unavailable. Local ad hoc signature validation is not Apple notarization/Gatekeeper distribution acceptance.
- 21 opt-in test prerequisites and names are in `evidence/opt-in-tests-not-rerun.json`; they are excluded from passing counts. Full formal Converge mutation/graph/TDD trace closure is not assembled.
- After GUI-only reopen, CUA twice timed out (`-10005`) while RPC and a GUI thread sample were normal. Restoring the normal GUI-first launch order under atomic zero-task admission immediately restored CUA. Same-executable process selection is suspected, not proven as a tool implementation fact; native window interactivity then passed again. No name/identifier change or parallel validation App was used.
